# От войны к войне: Европа 1914–1939

Интерактивная карта для занятий по истории межвоенного периода. Шкала из 21 шага ведёт от 1914 к сентябрю 1939 г. На каждом шаге: карта с границами своего времени, политика, общество и экономика, анализ, лидеры и вопрос для обсуждения.
